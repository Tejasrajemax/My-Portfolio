01 — About

I build the layer between raw data and human meaning.

I'm a Computer Science undergrad at Shobhit Institute of Engineering & Technology, Meerut, with a habit of picking projects that turn messy, real-world signals into something a person can actually use — a voice clip into an emotion label, a scroll of ratings into a recommendation, a stream of keystrokes into a readable log.

Most of what I know, I've built to learn: a Java banking system and a Java library management system built from first principles, a Flask-based recommendation engine, a keystroke-monitoring desktop app. I care as much about how software feels to use as how it works underneath — which is why the frontend gets the same attention as the logic behind it.
